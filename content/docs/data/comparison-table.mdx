## Usage

The differentiator beat of a launch video: a white table with hairline row
separators, the highlighted column wearing an accent header band and a soft
blue tint. Body rows stagger in; boolean cells draw a check stroke over 8
frames or fade in a muted cross.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ComparisonTable } from "@/components/snap-cn/comparison-table";

const Differentiator = () => (
  <ComparisonTable
    columns={[{ name: "Acme", highlight: true }, { name: "Legacy tools" }]}
    rows={[
      { label: "Setup time", values: ["5 min", "2 weeks"] },
      { label: "API access", values: [true, false] },
      { label: "Realtime sync", values: [true, false] },
      { label: "Support", values: ["24/7", "Email only"] },
    ]}
    rowStagger={10}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ComparisonTable"
    component={Differentiator}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

`columns` and `rows` also accept compact strings, which is handy when driving
the component from a customizer or CMS. A leading `*` highlights a column;
rows are `;`-separated with `|`-separated cells, and `yes/no` (or `✓/✗`)
cells become checks and crosses:

```tsx
<ComparisonTable
  columns="*Acme, Legacy tools"
  rows="Setup time | 5 min | 2 weeks; API access | yes | no; Realtime sync | yes | no; Support | 24/7 | Email only"
/>
```
