Reach for this category when a number carries the argument: "10k users", "3x faster", "us vs. them". These components animate counts, charts, and comparisons deterministically on the frame timeline, so the payoff lands exactly on the beat you schedule.

## Components

- [Counter](/docs/data/counter) — one animated number with three looks: continuous rolling places, a hold-then-spring odometer, and a per-character slot swap.
- [Stat Tile](/docs/data/stat-tile) — the composed big-stat proof beat: cards with count-up numbers, muted labels, and delta chips, staggered across a row.
- [Animated Line Chart](/docs/data/animated-line-chart) — KPI line chart that draws its path on with a no-bounce spring and a live counting headline value.
- [Animated Bar Chart](/docs/data/animated-bar-chart) — metric chart with staggered spring bars rising over hairline gridlines.
- [Progress Ring](/docs/data/progress-ring) — percentage ring or bar that sweeps to its target with a rolling count-up readout.
- [Comparison Table](/docs/data/comparison-table) — us-vs-them feature table with staggered rows, drawn checks, and an accent band on the highlighted column.
- [Data Flow Pipes](/docs/data/data-flow-pipes) — animated integration diagram where packets pulse along hairline pipes between product nodes.
