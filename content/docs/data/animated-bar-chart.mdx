## Usage

Drop it into a composition and feed it a metric. The default demo charts
deploys per weekday for a small team — midweek peak, quiet weekend:

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AnimatedBarChart } from "@/components/snap-cn/animated-bar-chart";

const DeploysScene = () => (
  <AnimatedBarChart
    title="Deploys per weekday"
    data={[34, 41, 46, 38, 29, 8, 5]}
    labels={["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DeploysPerWeekday"
    component={DeploysScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each bar grows from the baseline on a high-damping spring, offset by
`staggerFrames` from its neighbor, while the hairline grid and title fade in
underneath. Everything is driven by the current frame, so renders are
deterministic.
