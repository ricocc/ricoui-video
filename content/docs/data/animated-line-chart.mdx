## Usage

Built for the growth-metric beat in a product video: the line for a metric like
weekly active users draws on from left to right with a no-bounce spring, a leading
dot rides the edge of the stroke, and the headline value counts up in lockstep with
the reveal. The path length is computed analytically, so the draw speed is exact
and every frame is deterministic.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AnimatedLineChart } from "@/components/snap-cn/animated-line-chart";

const GrowthScene = () => (
  <AnimatedLineChart
    title="Weekly active users"
    data={[420, 460, 520, 610, 760, 1040, 1520, 2210, 2900, 3420, 3700, 3820]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AnimatedLineChart"
    component={GrowthScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The y-axis snaps to round tick values (0, 1k, 2k, ...) regardless of the raw data,
and x-labels default to `W1`, `W2`, ... — pass `xLabels` to use your own periods.
