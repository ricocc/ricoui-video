## Usage

The "how it works" beat of a B2B explainer: nodes fade in, then blue packets
travel the pipes on a repeating schedule — payment events land in Acme Core and
fan out to reporting and alerting. Node positions live in a 1280×720 viewBox,
each edge gets a `startFrame`, and everything is driven by the current frame,
so scrubbing and rendering are fully deterministic.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DataFlowPipes } from "@/components/snap-cn/data-flow-pipes";

const HowItWorksScene = () => (
  <DataFlowPipes
    nodes={[
      { id: "payments", x: 230, y: 360, label: "Payments" },
      { id: "core", x: 640, y: 360, label: "Acme Core" },
      { id: "reports", x: 1050, y: 252, label: "Reports" },
      { id: "alerts", x: 1050, y: 468, label: "Alerts" },
    ]}
    edges={[
      { from: "payments", to: "core", startFrame: 0 },
      { from: "core", to: "reports", startFrame: 30 },
      { from: "core", to: "alerts", startFrame: 38 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DataFlowPipes"
    component={HowItWorksScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

### Themes

The component is light-first and renders transparent — put it over a light
backdrop by default, or switch to `theme="dark"` for dark scenes. Individual
colors (`pipeColor`, `nodeColor`, `borderColor`, `textColor`) override the
theme when you need a custom palette.

```tsx
import { DataFlowPipes } from "@/components/snap-cn/data-flow-pipes";

<DataFlowPipes theme="dark" />
```

### Looping packets

Packets replay every `cycleFrames` frames (90 by default), so the diagram
stays alive for as long as the scene runs. Set `cycleFrames={0}` to fire each
packet exactly once.
