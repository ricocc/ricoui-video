## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Counter } from "@/components/snap-cn/counter";

const CounterScene = () => (
  <Counter from={0} to={128400} mode="odometer" prefix="$" fontSize={120} />
);

export const RemotionRoot = () => (
  <Composition
    id="Counter"
    component={CounterScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

## Modes

| Mode | Description |
| --- | --- |
| `rolling` | Every place travels continuously to its target with `Easing.out(Easing.poly(4))` — the ones spin roughly ten times as far as the tens, and new leading places rise gently into view. |
| `odometer` | Each place holds its digit, then spring-rolls (damping 200) through the last 10% of every rollover — the classic mechanical odometer tick. |
| `slot` | Per-character two-row swap between the padded `from`/`to` strings with a staggered spring per column. The only mode that accepts non-digit characters like `$` or `%`. |

Passing a string to `from` or `to` (e.g. `to="$199"`) forces slot mode regardless of `mode`.

The number renders in JetBrains Mono with tabular numerals on a transparent background, so it drops into any backdrop or stat tile. Rolling and odometer modes take non-negative integers only; direction (up or down) is inferred from the values.

## Odometer count-up

Counts to $128,400, each place ticking over mechanically:

```tsx
import { Counter } from "@/components/snap-cn/counter";

<Counter from={0} to={128400} mode="odometer" prefix="$" fontSize={120} />
```

## Slot price flip

String values force slot mode — every character reels from the old value to the new one:

```tsx
import { Counter } from "@/components/snap-cn/counter";

<Counter from="$99" to="$199" mode="slot" fontSize={120} />
```

## Odometer primitive

The module also exports `Odometer`, the readout behind `mode="odometer"`, for scenes that drive the value themselves (a count synced to another animation, for example):

```tsx
import { Odometer } from "@/components/snap-cn/counter";

<Odometer current={current} fontSize={64} color="#101828" />
```

It takes `current` (the exact continuous value to display), `fontSize`, and `color`, and renders with comma separators.

## Rolling count-down

Rolls downward, higher places fading out as the value shrinks:

```tsx
import { Counter } from "@/components/snap-cn/counter";

<Counter from={24813} to={0} mode="rolling" separator="space" fontSize={120} />
```
