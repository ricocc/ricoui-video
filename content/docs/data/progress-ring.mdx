## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ProgressRing } from "@/components/snap-cn/progress-ring";

const ProgressRingScene = () => (
  <ProgressRing value={87} sublabel="less manual entry" card />
);

export const RemotionRoot = () => (
  <Composition
    id="ProgressRing"
    component={ProgressRingScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

## Variants

| Variant | Description |
| --- | --- |
| `ring` | Circular SVG stroke that sweeps clockwise from the top, with the readout and sublabel centered inside. |
| `bar` | Horizontal track that fills left to right, with the sublabel on the left and the readout on the right of a header row. |

The sweep eases out over the first 70% of the composition and holds the target for the rest — the same `Easing.out(Easing.poly(4))` curve the counter's rolling mode uses, so the fill and the count-up stay perfectly in sync.

## Bar variant

The same stat as a filling skill bar — sublabel left, count-up right:

```tsx
import { ProgressRing } from "@/components/snap-cn/progress-ring";

<ProgressRing
  variant="bar"
  value={64}
  size={520}
  thickness={12}
  sublabel="Tickets resolved by Acme AI"
/>
```

## Static label

`label` swaps the percentage readout for any static string while the ring still sweeps to `value`:

```tsx
import { ProgressRing } from "@/components/snap-cn/progress-ring";

<ProgressRing value={98} label="4.9★" sublabel="average rating" />
```
