## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StatTile } from "@/components/snap-cn/stat-tile";

const ProofScene = () => (
  <StatTile
    layout="row"
    counterMode="rolling"
    stats={[
      {
        value: 12480,
        label: "Active users",
        delta: { value: "+23%", direction: "up" },
      },
      { value: "99.98", label: "Uptime", suffix: "%" },
      { value: "4.9", label: "Avg rating" },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="StatTile"
    component={ProofScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each tile composes the [Counter](/docs/data/counter): numeric values count up with
the chosen `counterMode`, while string values (`"99.98%"`, `"$199"`, `"4.9"`)
reel in with the slot animation. Tiles fade up one after another, `stagger`
frames apart, and each tile's counter starts on its own beat.

## The stats string form

`stats` also accepts a compact string — handy for quick edits and the
customizer. Each stat is `value | label | delta` (delta optional); stats are
separated by `;`. A delta starting with `-` points down, everything else up.
Integer values (commas allowed) count up; anything with a decimal point or
symbol plays as a slot reel.

```tsx
<StatTile stats="12,480 | Active users | +23%; 99.98% | Uptime; 4.9 | Avg rating" />
```

Tiles render on a transparent backdrop, so the row drops onto any scene
background. The number uses tabular numerals with tight tracking; the label
sits under it at 14px muted gray, with the delta chip beside it — success
green pointing up, danger red pointing down.

## Surprising-stat opener

One oversized number as a cold-open hook:

```tsx
import { StatTile } from "@/components/snap-cn/stat-tile";

<StatTile
  layout="single"
  counterMode="odometer"
  stats={[
    {
      value: 1299000,
      label: "Requests served daily",
      delta: { value: "+41%", direction: "up" },
    },
  ]}
/>
```
