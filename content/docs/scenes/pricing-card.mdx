## Usage

Drop it in as the differentiator/offer scene: cards fade up one by one, each
price counts in on the composed `Counter` reel, and feature rows check off
with a stagger. The popular tier gets a 1px accent border, an accent tint and
a "Most popular" badge. Everything derives from the current frame, so
scrubbing and rendering stay deterministic.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PricingCard } from "@/components/snap-cn/pricing-card";

const OfferScene = () => (
  <PricingCard
    tiers={[
      {
        name: "Starter",
        price: 0,
        period: "/mo",
        features: ["3 projects", "Community support", "Basic analytics"],
      },
      {
        name: "Pro",
        price: 29,
        period: "/mo",
        features: [
          "Unlimited projects",
          "Priority support",
          "Advanced analytics",
          "Team seats",
        ],
        popular: true,
      },
      {
        name: "Scale",
        price: 99,
        period: "/mo",
        features: [
          "Everything in Pro",
          "SSO & SCIM",
          "Dedicated success manager",
          "Custom SLA",
        ],
      },
    ]}
    layout="row"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PricingCard"
    component={OfferScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

### Compact string form

`tiers` also accepts a compact string — handy for quick edits and the site
customizer. Each tier is `name | price | period | features | popular`
(features comma-separated, tiers separated by `;`). A non-empty 5th field
marks the popular tier: the keyword `popular` keeps the default badge, any
other text becomes the badge.

```tsx
<PricingCard tiers="Starter | 0 | /mo | 3 projects, Community support; Pro | 29 | /mo | Unlimited projects, Team seats | popular; Scale | 99 | /mo | Everything in Pro, Custom SLA" />
```

### Single hero card

`layout="single"` shows just the popular tier (or the first, when none is
marked) as one larger centered card — for a beat that spotlights the offer.

```tsx
<PricingCard layout="single" />
```

## Layouts

- `row` — all tiers side by side, entering left to right with `cardStagger`.
- `single` — one hero card: the popular tier if any, otherwise the first.
