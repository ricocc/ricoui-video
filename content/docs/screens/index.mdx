This is the category for showing product. Wrap a recording or live UI in device chrome, or simulate a terminal or AI-tool session entirely in code. Reach for it in the demo section of a launch video — anywhere a screen is the subject of the shot.

## Components

- [Phone Frame](/docs/screens/phone-frame) — iPhone-style device frame with a dynamic island, flat or lightly 3D-tilted, with rise, rotate-in, or float entrances.
- [Terminal Simulator](/docs/screens/terminal-simulator) — terminal window with chunked command playback, freeze-frame pauses, step scrolling, and an optional cursor-pinned zoom.
- [Claude Chat](/docs/screens/claude-chat) — animated Claude chat screen: a prompt types in, the send button morphs, and the reply streams in.
- [v0](/docs/screens/v0) — simulated v0 composer screen that types a build prompt while the mic button morphs into send.
