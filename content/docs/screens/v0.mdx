## Usage

The prompt-entry screen for an AI-builder storyline: a clean composer over a
token-aligned canvas, a greeting, and a prompt that types itself in. Use it as
the first `<Sequence>` of a build-with-AI demo, then cut to your generated-app
scene to show it taking over the frame.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { V0 } from "@/components/snap-cn/v0";

const PromptScene = () => (
  <V0
    greeting="What should we build today?"
    prompt="Generate a pricing page for Acme"
    projectName="acme-web"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="V0"
    component={PromptScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Timeline: heading + composer ease in (0–16), the empty state holds with a
blinking caret (16–42), the prompt types in from frame 42, and the mic button
morphs into a send button the instant the first character lands, then the frame
holds to the end — a natural cut point into the next scene.

### As the opener of an AI-builder demo

Sequence it ahead of your generated-app scene: the prompt screen sells the ask,
the next scene sells the result.

```tsx
import { Sequence } from "remotion";
import { V0 } from "@/components/snap-cn/v0";

<>
  <Sequence durationInFrames={150}>
    <V0 prompt="Generate a pricing page for Acme" projectName="acme-web" />
  </Sequence>
  <Sequence from={150} durationInFrames={120}>
    <GeneratedAppScene />
  </Sequence>
</>
```

### Themes

The component renders transparent; light is the default. Set `theme="dark"` for
a dark surface and pair it with a dark canvas:

```tsx
import { V0 } from "@/components/snap-cn/v0";

<V0 theme="dark" prompt="Generate a pricing page for Acme" />
```

## Notes

- **Deterministic:** All motion is driven by `useCurrentFrame` — scrubbing and MP4 renders are frame-exact.
- **Button morph:** The mic-to-send morph is gated purely on text presence — the moment the prompt has any characters, the send button appears.
- **Offline-friendly:** No network requests or images, so the preview works offline and export needs no CORS setup.
- **Shared hook:** Reuses the `useTypewriter` hook and the `caret` primitive shared with the other chat screens.
