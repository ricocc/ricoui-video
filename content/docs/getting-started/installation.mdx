snap-cn assumes you already have Remotion installed. If you don't, run `npx create-video@latest` first.

## 1. Initialize shadcn

If your project doesn't already have a `components.json`, run:

```bash
npx shadcn@latest init
```

Pick the defaults: snap-cn components are framework-agnostic and only need the path aliases.

## Shorter commands, if you want them

Installing more than one or two? Register the namespace once and you can use `@snap-cn/<name>` instead of the full URL:

```bash
npx shadcn@latest registry add '@snap-cn=https://snapcn.dev/r/{name}.json'
```

Keep the quotes. `{name}` is a literal placeholder the CLI fills in per component, and an unquoted brace is something your shell may decide it owns. After this, `npx shadcn@latest add @snap-cn/text-reveal` works, and so does the bulk command below.

This is optional. It is here because the URLs get repetitive, not because anything needs it.

## 3. Use it in a Remotion composition

```tsx
import { Composition } from "remotion";
import { TextReveal } from "@/components/snap-cn/text-reveal";

export const RemotionRoot = () => (
  <Composition
    id="HelloWorld"
    component={TextReveal}
    durationInFrames={60}
    fps={30}
    width={1280}
    height={720}
    defaultProps={{ text: "Hello, world" }}
  />
);
```

That's it. Render with `npx remotion render HelloWorld out.mp4`.
